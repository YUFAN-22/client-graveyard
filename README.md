# Client Graveyard · 甲方墓园

> **Bury the project. Keep the lesson.**  
> 一个用于项目复盘、情绪释放和记录合作教训的本地像素 Web App。

甲方墓园把一次次“难忘合作”变成可浏览的像素墓碑：记录甲方特质、合作事件和项目教训；想放下时可以上一炷香，想发泄时可以扔一个 💩。核心数据默认只保存在用户自己的浏览器里。

## 视觉版本

当前版本为 **Arcade Pixel v1.1**：采用复古掌机 / 街机式像素 UI，桌面端固定 4 列墓碑、手机端固定 2 列，墓碑按同一地面基线底部对齐。中文信息使用高可读粗黑字体，英文 HUD 保留像素终端感。

### 单文件本地版

如果只想下载一个文件直接双击使用，请打开 `preview.html`（与 `standalone.html` 内容相同）。CSS 和 JavaScript 已全部内嵌，不需要保留 `css/`、`js/` 文件夹。

## 功能

- 🪦 像素墓园：桌面端每行 4 块墓碑，手机端每行 2 块
- 📝 甲方档案：姓名/代号、特质、立碑日期、墓志铭、墓碑皮肤
- 📜 往事时间轴：支持无限添加、编辑、删除合作事件
- 🕯️ 上香：像素蜡烛、烟雾、随机复盘文案，停留约 5 秒
- 💩 扔大便：抛物线命中、墓碑震动、随机吐槽文案
- 🌱 墓碑状态：随 💩 数量出现杂草、裂纹、乌鸦和“重点纪念”状态
- 🔎 搜索与特质筛选
- 📊 墓园管理局：墓碑、事件、上香、💩、常见特质和年度统计
- 🏆 成就系统与彩蛋
- 📅 今日祭扫
- 🌙 自动昼夜 / 手动昼夜切换
- 🌫️ 晴 / 雾 / 雨环境效果
- ♪ 可选本地生成环境音，不加载外部音频
- ▧ 生成 16:9 PNG 分享卡
- 💾 JSON 导入、导出、清空与旧版数据迁移
- 🔒 无账号、无服务器、无第三方统计、无外部依赖

## 快速使用

### 方式 A：直接打开

下载整个项目后打开 `index.html` 即可。现代浏览器通常可以直接使用本地存储；若浏览器的隐私策略禁止本地存储，页面会自动降级到当前会话内存，此时请及时导出 JSON 备份。

### 方式 B：本地静态服务器（推荐开发时使用）

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 发布到 GitHub Pages

1. 创建 GitHub 仓库并上传本项目全部文件。
2. 打开仓库 **Settings → Pages**。
3. Source 选择 **Deploy from a branch**。
4. Branch 选择 `main`，目录选择 `/ (root)`。
5. 保存后等待 GitHub Pages 生成公开地址。

项目是纯静态 HTML/CSS/JavaScript，不需要构建步骤。

## 数据与隐私

- 数据默认使用浏览器 `localStorage` 保存。
- 项目不会主动把用户输入上传到服务器。
- 不需要注册、登录或提供账号信息。
- 建议用昵称、代号或项目代称，不要记录手机号、住址、证件号码、银行账号、公司机密等敏感信息。
- 公开截图、分享卡或备份文件前，请自行检查是否包含可以识别具体个人的信息。
- 清除浏览器网站数据会删除本地墓园，请定期导出 JSON 备份。

## 旧版兼容

新版会尝试读取旧 Demo 使用的 `client_graveyard_v1` 数据，并自动转换为新版结构。旧版的姓名、特质、立碑时间、事件、蜡烛数和 💩 数会尽量保留。

## 墓碑等级

| 💩 数量 | 状态 |
|---:|---|
| 0–9 | 普通墓碑 |
| 10–29 | 增加杂草 |
| 30–59 | 墓碑出现裂纹 |
| 60–99 | 出现乌鸦和更明显的破损 |
| 100+ | “重点纪念”状态 |

## 安全与使用边界

这是一个用于私人项目复盘、情绪表达和自嘲的工具，不提供公开真人数据库、公开排行榜或云端甲方信息共享功能。建议保持“记录经历，而不是围攻个人”的使用方式。

## 浏览器支持

建议使用近期版本的 Chrome、Edge、Firefox 或 Safari。页面没有第三方依赖，核心功能可以离线使用。
